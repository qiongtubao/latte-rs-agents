<instruction>
- Use to create or update documentation files that are tracked by the doc graph.
- Automatically updates the doc graph index after writing.
- Use for: READMEs, API docs, architecture docs, guides.
</instruction>

<critical>
- NEVER use for source code files — use `write` tool instead.
- Ensure documentation is consistent with actual code behavior — don't document aspirational features.
- Follow existing documentation style and structure in the project.
</critical>
