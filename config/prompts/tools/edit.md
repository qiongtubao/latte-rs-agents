<instruction>
- `edit` 的一个 op 由「**定位**」和「**替换内容**」两部分组成，写在**同一个 op 里**：
  1. **定位**二选一：`old_text`（按内容锚定，不依赖行号，**优先用这个**，只取能唯一定位的几行，别贴整大段），
     或 `start_line` [+ `end_line`]（按行号）。两个都给时以 `old_text` 为准，`start_line` 只是提示
     （`old_text` 出现多处时，选离它最近的一处）。
  2. **替换内容**统一叫 `new_text`（`new_content` 是旧名，也认）。
  3. **删除**：加 `"delete": true`；文本定位只给 `old_text` 不给 `new_text` 也按删除处理（会在 `warnings` 里提示）。
  4. 行号插入：`insert_after` / `insert_before` + `start_line` + `new_text`。
  - **不要把定位和替换内容拆成两个 op**（只有替换内容、前面没有可配对的 `old_text` 会被拒绝）。
- **行号安全是自动的**：运行时会根据你**此前 `read` 看到的内容**，自动给行号操作补上
  `expect`（那几行的原文）与文件快照 `tag`，你不必手动传。
  - 行号若有小偏移 → 工具按内容在全文唯一定位后**自动改到正确的行**，并在 `warnings` 说明；
  - 内容已面目全非、无法唯一定位 → 编辑被**拒绝**，请重新 `read` 再改。
- 你也可以显式传 `expect` / `tag`；显式给的值优先，不会被覆盖。想更稳时值得手动带上
  `expect`（尤其是你**没有**先 read 就要按行号改的场合——那时没有自动兜底）。
</instruction>

<critical>
- **改之前先 read**：自动锚定的依据来自你 read 到的内容。没读过就按行号改 = 没有任何
  保护（工具无从判断那几行是不是你以为的东西）。
- 返回值里的 `warnings` 必须读：它会告诉你工具替你做了什么订正（行号重定位、
  宽松匹配、快照过期转内容校验）。据此更新你对文件的认知，别当作没发生。
- 编辑被拒绝时**不要原样重试**——重试必然再失败。按提示重新 `read` 拿到当前内容与
  行号，或改用 `old_text` 内容锚定。
- `old_text` / `expect` 在文件里**出现多处**（歧义）→ 编辑被拒绝。请多带几行上下文
  让锚点唯一；确实要改全部出现处时，显式传 `"all": true`（会在 `warnings` 里回报改了几处）。
- `old_text` 逐字节匹配不到时，工具会依次放宽「忽略行尾空白」「忽略缩进」再唯一定位，
  所以缩进/尾随空格的细微差异不必反复纠结；但**内容本身必须对**。
- 用 `write` 创建或整体覆盖文件；`edit` 只改已存在的文件。
</critical>
