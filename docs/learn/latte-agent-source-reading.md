# 《latte-agent 源码精读》

一本带读 latte-rs-agents 仓库源码的渐进式教材：每章聚焦一个真实模块，从「这是什么、整体怎么运转」讲起，逐段精读代码、标注 `file:line` 出处，并为每个知识点提供可上手的判断场景题。目标是读完能自己讲清模块的行为与边界，而不是记住行号。

全书按「编 → 章」组织，章节编号形如 `1.1`（第 1 编第 1 章）。每章都有一条由浅入深的先修链，请按章节号顺序阅读。
